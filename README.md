# SAAZ IDEA — موقع الشركة (React)

موقع React حديث لساز آيديا (مركز عناية وحماية سيارات — PPF، عازل حراري، نانو سيراميك، تلميع احترافي): تبديل وضع فاتح/داكن، دعم كامل للعربية والإنجليزية (RTL/LTR)، خدمة حجوزات، قسم عروض، تقييمات جوجل، خريطة الموقع، وقسم فيديوهات انستغرام.

> **ملاحظة:** معظم المحتوى الآن حقيقي (من نحن، الخدمات، لماذا تختارنا، التقييمات، العنوان، الجوال). الصور لا تزال جزئيًا placeholder (تدرّج لوني + أيقونة) في قسم الخدمات والعروض وأعمالنا، لأن عندنا صورتين حقيقيتين فقط (الهيرو ومن نحن). راجعوا قسم "استبدال الصور المتبقية" بالأسفل لإكمالها.

## التشغيل محلياً

```bash
npm install
npm run dev       # تشغيل بيئة التطوير
npm run build     # بناء نسخة الإنتاج (تُنتج مجلد dist/)
npm run preview   # معاينة نسخة الإنتاج
```

## 1) استبدال الصور المتبقية

- **موجودة فعليًا (حقيقية):** `public/images/hero-detailing.webp` و `public/images/about-showroom.webp`، مستخدمة في `Hero.tsx` و `About.tsx`.
- **لا تزال placeholder:** صور بطاقات `Services.tsx`، `Offers.tsx`، و `Portfolio.tsx` (تدرّج كحلي/ذهبي + أيقونة عبر `ImagePlaceholder.tsx`). لاستبدال أي منها: ضعوا الصورة في `public/images/`، ثم استبدلوا `<ImagePlaceholder ... />` بـ `<img src="/images/xxx.jpg" ... className="h-44 w-full object-cover" />` (نفس الأبعاد تقريبًا).
- **الشعار:** أعدنا رسمه كتقريب SVG من شعاركم الفعلي (`src/components/Logo.tsx`) لأننا ما قدرنا نحفظ ملف الشعار الأصلي من المحادثة. لمطابقة تامة، أرسلوا ملف الشعار (SVG أو PNG بخلفية شفافة) وسنستبدله مباشرة بالملف الأصلي.

## 2) خدمة الحجوزات (البريد الإلكتروني)

النموذج في `src/components/Booking.tsx` يرسل البيانات إلى بريد **saazidea@gmail.com** عبر خدمة [Formspree](https://formspree.io) (اخترتوها كأسهل حل بدون سيرفر خاص):

1. أنشئوا حساب مجاني على formspree.io.
2. أنشئوا نموذج (Form) جديد واربطوه ببريد `saazidea@gmail.com`.
3. انسخوا معرّف النموذج (Form ID) من رابط النموذج (الجزء بعد `/f/`).
4. أنشئوا ملف `.env` في جذر المشروع (انسخوا من `.env.example`) وضعوا فيه:
   ```
   VITE_FORMSPREE_ID=xxxxxxxx
   ```
5. إذا نشرتوا عبر Vercel: أضيفوا نفس المتغير `VITE_FORMSPREE_ID` من إعدادات المشروع (Settings → Environment Variables) قبل البناء — راجعوا قسم النشر بالأسفل.

عند إرسال أي طلب حجز، يوصل بريد فوري لـ saazidea@gmail.com بكل بيانات العميل (الاسم، الجوال، الإيميل، نوع الخدمة، التاريخ، والتفاصيل)، وفريقكم يتواصل مع العميل من هناك مباشرة.

## 3) قسم فيديوهات انستغرام

الملف: `src/config/instagramReels.ts`

ضعوا روابط الريلز الحقيقية (يجب أن تكون منشورات عامة/public) في المصفوفة:

```ts
export const INSTAGRAM_REELS: string[] = [
  "https://www.instagram.com/reel/XXXXXXXXXXX/",
  "https://www.instagram.com/reel/YYYYYYYYYYY/",
]
```

وحدّثوا `INSTAGRAM_PROFILE_URL` برابط حسابكم الفعلي (حاليًا `saazidea` كتخمين — تأكدوا منه). الفيديوهات تبقى مرفوعة على انستغرام فعليًا (Embed رسمي) وتُعرض مباشرة داخل الموقع. إذا تُركت المصفوفة فارغة، يظهر قسم "قريباً" مع زر "تابعنا على انستغرام".

## 4) قسم العروض

الملف: `src/components/Offers.tsx` (والنصوص في `offers.items` داخل ملفي الترجمة `ar.json`/`en.json`). أضيفوا/عدّلوا/احذفوا عروض بتعديل مصفوفة `items` بنفس البنية.

## 5) تقييمات العملاء (Google Maps)

الملف: `src/config/testimonials.ts` — يحتوي حاليًا 4 تقييمات حقيقية منقولة من لقطة شاشة أرسلتوها. لإضافة تقييمات جديدة، أضيفوا عنصرًا جديدًا لنفس المصفوفة (`name`, `text`, `rating`, `timeAgo`, و`avatarUrl` اختياري إذا توفرت صورة). الزرّان "شاهد/شارك تقييمك على Google Maps" يفتحان رابط خرائط جوجل الحقيقي حق المعرض.

> **للربط الحي بـ Google Places API** (تحديث تلقائي للتقييمات بدل تعديلها يدويًا): يتطلب حساب Google Cloud + تفعيل Places API + مفتاح API مقيّد بدومين موقعكم. تواصلوا معنا إذا تبغون نفعّل هذا الخيار.

## 6) خريطة الموقع

الملف: `src/config/location.ts`. رابط خرائط جوجل الحقيقي مضاف (`GOOGLE_MAPS_URL`)، وزر "افتح في خرائط جوجل" يفتحه مباشرة. أما الخريطة المُضمّنة (iframe) فهي بحث نصي تقريبي باسم "SAAZ IDEA جدة" لأننا ما قدرنا نحلّل الرابط المختصر لإحداثيات دقيقة من بيئة التطوير (لا يوجد اتصال إنترنت هنا). **لتفعيل الموقع الدقيق:** افتحوا Google Maps → ابحثوا عن المعرض → مشاركة → "تضمين خريطة" → انسخوا رابط الـ `src` (يبدأ بـ `https://www.google.com/maps/embed?pb=...`) والصقوه في `GOOGLE_MAPS_EMBED_SRC`.

## 7) بوب أب عروض اليوم الوطني

الملف: `src/components/NationalDayPopup.tsx` والنصوص في `nationalDay` داخل ملفي الترجمة. يظهر مرة واحدة لكل جلسة تصفح (`sessionStorage`) بعد ثانية تقريبًا من فتح الموقع، ويحتوي رقم الجوال/واتساب فقط بدون نسبة خصم محددة. لإيقافه مؤقتًا (بعد انتهاء المناسبة)، احذفوا `<NationalDayPopup />` من `src/App.tsx`.

## 8) بيانات التواصل

الملف: `src/config/contact.ts` — رقم الجوال/واتساب الحقيقي. لتحديثه مستقبلاً، عدّلوا القيم هناك (تُستخدم تلقائيًا في الفوتر، البوب أب، وأي مكان آخر).

## البنية التقنية

- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4** — الألوان (كحلي + ذهبي مطابقة للشعار) والخطوط في `src/index.css`
- **react-i18next** — نظام الترجمة والتبديل بين اللغتين (`src/i18n`)
- **الوضع الفاتح/الداكن** — يُحفظ في المتصفح (`localStorage`)، ويتبع تفضيل النظام تلقائياً عند أول زيارة
- **RTL/LTR تلقائي** حسب اللغة المختارة

## النشر على Vercel

المشروع Vite قياسي، Vercel يتعرف عليه تلقائيًا (zero-config):

1. ارفعوا المشروع إلى مستودع GitHub (أو استخدموا الفرع الحالي).
2. من لوحة Vercel: **Add New → Project** → اختاروا المستودع.
3. Framework Preset: **Vite** (يُكتشف تلقائيًا) — Build Command: `npm run build`, Output Directory: `dist`.
4. **Settings → Environment Variables**: أضيفوا `VITE_FORMSPREE_ID` بقيمته.
5. **Deploy**. أي دفعة (push) جديدة على الفرع المربوط تُنشر تلقائيًا.

بديل سريع من جهازكم (بدون GitHub): `npx vercel` من داخل مجلد المشروع بعد تسجيل الدخول بحساب Vercel.
