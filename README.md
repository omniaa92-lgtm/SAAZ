# SAAZ IDEA — موقع الشركة (React)

موقع React حديث لساز آيديا: تبديل وضع فاتح/داكن، دعم كامل للعربية والإنجليزية (RTL/LTR)، خدمة حجوزات، قسم عروض، وقسم فيديوهات انستغرام.

> **ملاحظة مهمة:** كل النصوص والصور الحالية في الموقع **مؤقتة** (placeholder). ما قدرنا نوصل لموقع saazidea.com الحقيقي لسحب المحتوى والصور بسبب قيود شبكة بيئة التطوير، فبنينا الموقع بمحتوى نموذجي واقعي بانتظار المحتوى الفعلي منكم. راجعوا قسم "استبدال المحتوى" بالأسفل.

## التشغيل محلياً

```bash
npm install
npm run dev       # تشغيل بيئة التطوير
npm run build     # بناء نسخة الإنتاج (تُنتج مجلد dist/)
npm run preview   # معاينة نسخة الإنتاج
```

## 1) استبدال المحتوى (نصوص وصور)

- **النصوص العربية:** `src/i18n/locales/ar.json`
- **النصوص الإنجليزية:** `src/i18n/locales/en.json`
- **الصور:** كل الصور حالياً عبارة عن بلوكات تدرّج لوني مؤقتة (`src/components/ImagePlaceholder.tsx`). لاستبدالها بصور حقيقية، ضعوا الصور داخل مجلد `public/images/` واستبدلوا مكوّن `<ImagePlaceholder ... />` بوسم `<img src="/images/xxx.jpg" ... />` في الملفات التالية: `Hero.tsx`، `About.tsx`، `Services.tsx`، `Offers.tsx`، `Portfolio.tsx`.
- **الشعار:** حالياً حرف "S" داخل مربع متدرّج في `Header.tsx` و `Footer.tsx`. استبدلوه بشعار SVG/PNG الحقيقي.
- **رقم الجوال:** ابحثوا عن `+966 5X XXX XXXX` في ملفي الترجمة واستبدلوه برقم التواصل الحقيقي.

## 2) خدمة الحجوزات (البريد الإلكتروني)

النموذج في `src/components/Booking.tsx` يرسل البيانات إلى بريد **saazidea@gmail.com** عبر خدمة [Formspree](https://formspree.io) (اخترتوها كأسهل حل بدون سيرفر خاص):

1. أنشئوا حساب مجاني على formspree.io.
2. أنشئوا نموذج (Form) جديد واربطوه ببريد `saazidea@gmail.com`.
3. انسخوا معرّف النموذج (Form ID) من رابط النموذج (الجزء بعد `/f/`).
4. أنشئوا ملف `.env` في جذر المشروع (انسخوا من `.env.example`) وضعوا فيه:
   ```
   VITE_FORMSPREE_ID=xxxxxxxx
   ```
5. أعيدوا تشغيل `npm run dev` أو ابنوا المشروع من جديد.

عند إرسال أي طلب حجز، يوصل بريد فوري لـ saazidea@gmail.com بكل بيانات العميل (الاسم، الجوال، الإيميل، نوع الخدمة، التاريخ، والتفاصيل)، وفريق المبيعات يتواصل مع العميل من هناك مباشرة.

> بديل: إذا تفضلون حل آخر (نظام CRM، بريد عبر سيرفر خاص بكم، أو WhatsApp Business API)، الكود قابل للتعديل بسهولة — تواصلوا لتحديثه.

## 3) قسم فيديوهات انستغرام

الملف: `src/config/instagramReels.ts`

ضعوا روابط الريلز الحقيقية (يجب أن تكون منشورات عامة/public) في المصفوفة:

```ts
export const INSTAGRAM_REELS: string[] = [
  "https://www.instagram.com/reel/XXXXXXXXXXX/",
  "https://www.instagram.com/reel/YYYYYYYYYYY/",
]

export const INSTAGRAM_PROFILE_URL = "https://www.instagram.com/saazidea/"
```

الفيديوهات تبقى مرفوعة على انستغرام فعلياً (Embed رسمي من انستغرام) وتُعرض مباشرة داخل الموقع. إذا تركتوا المصفوفة فارغة، يظهر قسم "قريباً" مع زر "تابعنا على انستغرام".

## 4) قسم العروض

الملف: `src/components/Offers.tsx` (والنصوص في `offers.items` داخل ملفي الترجمة). أضيفوا/عدّلوا/احذفوا عروض بتعديل مصفوفة `items` في `ar.json` و `en.json` بنفس البنية.

## البنية التقنية

- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4** — الألوان والخطوط في `src/index.css`
- **react-i18next** — نظام الترجمة والتبديل بين اللغتين (`src/i18n`)
- **الوضع الفاتح/الداكن** — يُحفظ في المتصفح (`localStorage`)، ويتبع تفضيل النظام تلقائياً عند أول زيارة
- **RTL/LTR تلقائي** حسب اللغة المختارة

## النشر (Deploy)

المشروع ثابت (static) بالكامل بعد البناء (`npm run build` → مجلد `dist/`)، يمكن نشره على Vercel، Netlify، Cloudflare Pages، أو أي استضافة تدعم مواقع ثابتة. تذكّروا إضافة متغير البيئة `VITE_FORMSPREE_ID` في إعدادات المنصة قبل البناء.
